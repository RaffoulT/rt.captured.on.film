How it works: this is a lightweight client-side admin for a static site. Changes are saved in this browser only (localStorage) and are shown on index.html. Because there is no server, the password gate is a convenience lock, not real security — anyone who uses this computer can open the page. Use Export JSON regularly to back up your catalogue, and Import JSON to restore it on another browser/device.
